# EMORA v2

Premium animated emotional mini-site platform MVP.

## Included
- 5 occasion categories
- 10 templates per category (50 total)
- UZ / RU / EN UI
- Template filters and animated live previews
- Template and AI-assisted builder flows
- Personalization: recipient, sender, message, photo URL, accent color, final line
- Shareable short links backed by the EMORA API
- Cross-device reaction analytics and view counts
- Click / Payme-ready payment step UI (merchant credentials still required for real payment processing)
- Railway health endpoint at `/health`

## Run
```bash
npm start
```
